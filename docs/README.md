## 写文档的约定

1. **进度表只追加、不改历史**：旧日期那节保持原样，新的另起一节。
2. **数字要能追**：写「命中率 96.3%」得同时写清是哪套基准（PUB01 108 题）、修前是多少。
3. **已知限制不藏**：沙箱里过不了的测试、没验过的界面，直接写在「已知限制」里。
4. 对外文档（`README.md`、`CHANGELOG.md`）不写本机路径和真实记忆样本。
